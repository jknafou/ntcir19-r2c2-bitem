# GPU / inference environment: exact pins, as a pip fallback.
#
# The canonical way to reproduce the environment is `uv sync` (pyproject.toml +
# uv.lock). This file is for environments that cannot use uv.lock. It is a
# complete, flat closure of the Python environment behind the NTCIR-19 R2C2
# submission (vLLM 0.17.1 / torch 2.10.0+cu129 / transformers 5.5.4 / CUDA 12.9).
#
# Target interpreter: CPython 3.12.3 (vLLM 0.17.1 has no 3.14 wheels).
#
# Preferred build (single project venv, all phases):
#   uv sync          # reads pyproject.toml + uv.lock; no extra flags needed
#
# Pip fallback (both extra flags are required, see below):
#   uv venv --python 3.12.3 .venv
#   uv pip install --python .venv/bin/python \
#       --index-strategy unsafe-best-match --no-deps \
#       -r requirements-gpu.txt
#
#   --index-strategy unsafe-best-match : the cu129 index also serves common
#       packages (certifi, ...) at old versions; without this flag uv pins them
#       to the first index that has them and the resolve fails. The flag lets
#       uv pick the best version across PyPI + cu129 (the +cuNNN pins still
#       force the correct torch build).
#   --no-deps : every one of the 238 packages is pinned explicitly. The
#       environment pins transformers==5.5.4, which violates vLLM 0.17.1's
#       `transformers<5` constraint, so uv's strict resolver rejects the graph
#       ("vllm 0.17.1 depends on transformers>=4.56.0,<5"). --no-deps installs
#       the exact frozen set without re-resolving. (`uv sync` applies the same
#       override through [tool.uv] override-dependencies and needs no flags.)
#       Do not lower transformers to <5: 4.x cannot load Qwen3.5-9B.
#
# Index sources (uv reads the --extra-index-url lines below directly):
#   * torch / torchvision / torchaudio  -> PyTorch CUDA 12.9 index
#       https://download.pytorch.org/whl/cu129   (the +cu129 local-version
#       wheels do not exist on PyPI; cu128 and cu129 are different builds).
#   * everything else                   -> PyPI (default index).
#   * llamafactory                      -> pinned git commit (training only;
#       part of the environment, kept for an exact match).
#
# A fresh build of this file gives a `uv pip freeze` identical to that of the
# submission environment (238 packages, same +cu129 tags).
